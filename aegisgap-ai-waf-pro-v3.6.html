Layer A · Internet-Facing Edge-Client WAF

Inspection runs inside this browser context, in front of every AI call. Malicious payloads, prompt injections and scanner floods are dropped locally — the request never leaves the machine, so no upstream endpoint is exposed, contacted, or billed. This is the first line, not the last: the same sentinel-edge.js also runs server-side (Node / Lambda / edge workers under server-integration/), where your backend re-checks every request before any API key is attached — DevTools cannot bypass that gate (DEPLOYMENT §15, §18).

    Data Protection · PII / PHI · SSRF

    Validated detectors (Luhn cards, Aadhaar Verhoeff, IBAN mod-97, SSN structure, email, phone, PAN) plus PHI (MRN, DOB, ICD-10, insurance / NPI IDs, named-patient diagnoses). Masked values are replaced by [MASKED:CARD] style tokens in the request body before it leaves the browser.

    System-Prompt Leak Shield
    not protected

    Only one-way hashes of 7-word windows are stored — the prompt text is discarded the moment you save. Every model reply (also its Base64/Hex/URL-decoded views) is compared: ≥10 verbatim words = HIGH, ≥20 words or ≥20 % coverage = CRITICAL block LEAK-001. Paraphrases are not detected.

    RBAC is decided by your origin, not by this page. Enabling it makes the engine ask GET /api/session who you are; the origin answers from an HttpOnly cookie the browser can send but JavaScript cannot read. Set the policy origin above first.

    Honest limits: the role now comes from a server-side session behind an HttpOnly cookie, and nothing permission-bearing is written to localStorage or sessionStorage — so there is no stored hash to edit from DevTools. The engine caches the origin's answer for 30 s and answers deny whenever that cache is cold or stale; the origin locks out an IP for 60 s after 5 failed sign-ins. What this does not solve: an attacker who controls the browser can still call your APIs directly with the session cookie attached. That is what the server-side mirror (Layer C) is for, and why governed fields are signed rather than merely stored.
